# Plukrunde-beregner

Beregner, der sammenligner to lagerlayouts ud fra antal gange, pallepladser og en ordreprofil. Den viser, hvor mange meter, minutter og kroner en plukrunde koster. Den er lavet til Komergo-casen (Distribution & SCM, 3. semester logistikøkonom) med Hammelev og München som eksempel.

Siden er én HTML-fil (`index.html`) uden byggetrin.

## Sådan bruges den

1. Åbn siden. Hammelev (layout A) og München (layout B) er udfyldt som eksempel.
2. Ret ordreprofil, tider og omkostninger i venstre kolonne. De gælder for begge layouts.
3. Ret gange, pallepladser, niveauer og plukmetode under hvert layout.
4. Læs resultatet i "Sammenligning" øverst. Grøn markerer det bedste af de to.
5. Se under "Antagelser", hvilke tal der kommer fra casen, og hvilke der er antaget.
6. Se under "Mellemregninger", hvordan hvert resultat er regnet ud.
7. Klik "Nulstil til eksempel" for at starte forfra. Dine tal gemmes kun i din egen browser.
